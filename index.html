Chrome Extension — GoldLock
افزونهٔ کروم — قفل طلایی (GoldLock)

1Overview

GoldLock is a Chrome extension designed to protect normal web browsing with a user-defined password.

This Privacy Policy explains what information GoldLock stores, how it is used, and what information is not collected or transmitted.

۱مرور کلی

قفل طلایی افزونه‌ای برای کروم است که با گذرواژه‌ای که کاربر تعیین می‌کند، از مرور عادی وب محافظت می‌کند.

این سیاست حریم خصوصی توضیح می‌دهد قفل طلایی چه اطلاعاتی را ذخیره می‌کند، چگونه از آن‌ها استفاده می‌شود و چه اطلاعاتی جمع‌آوری یا منتقل نمی‌شوند.

2Data Storage

GoldLock stores security settings and extension preferences locally in the user's Chrome profile. This may include:

  • Password verification data and cryptographic salt.
  • Recovery Key verification data and cryptographic salt.
  • Selected language and lock-related preferences.
  • Other settings required for GoldLock to operate.

Passwords and Recovery Keys are not stored in plain text.

۲ذخیره‌سازی داده‌ها

قفل طلایی تنظیمات امنیتی و ترجیحات افزونه را به‌صورت محلی در نمایهٔ کروم کاربر ذخیره می‌کند. این موارد ممکن است شامل موارد زیر باشند:

  • دادهٔ تأیید گذرواژه و نمک رمزنگاری؛
  • دادهٔ تأیید کلید بازیابی و نمک رمزنگاری؛
  • زبان انتخاب‌شده و ترجیحات مربوط به قفل؛
  • تنظیمات دیگری که برای کارکرد قفل طلایی لازم‌اند.

گذرواژه‌ها و کلیدهای بازیابی به‌صورت متن ساده ذخیره نمی‌شوند.

3Browsing and Navigation Data

GoldLock processes browser navigation information locally when necessary to enforce its core browser-lock feature. When the browser is locked, GoldLock may use the destination URL of a protected navigation to redirect the tab to the GoldLock lock screen and restore access after successful authentication.

Important: GoldLock does not collect, sell, rent, or share browsing history, webpage content, passwords, Recovery Keys, or other personal information with external servers.

۳داده‌های مرور و پیمایش

قفل طلایی در صورت نیاز، اطلاعات پیمایش مرورگر را به‌صورت محلی پردازش می‌کند تا قابلیت اصلی قفل مرورگر را اجرا کند. هنگام قفل‌بودن مرورگر، قفل طلایی ممکن است از نشانی مقصدِ یک پیمایش محافظت‌شده استفاده کند تا زبانه را به صفحهٔ قفل قفل طلایی هدایت کند و پس از احراز هویت موفق، دسترسی را بازگرداند.

مهم: قفل طلایی سابقهٔ مرور، محتوای صفحه‌های وب، گذرواژه‌ها، کلیدهای بازیابی یا سایر اطلاعات شخصی را جمع‌آوری نمی‌کند و آن‌ها را به سرورهای بیرونی نمی‌فروشد، اجاره نمی‌دهد یا به اشتراک نمی‌گذارد.

4Accounts and Online Recovery

GoldLock does not require a user account, email address, or online recovery service. Recovery is designed to work offline using the user's Recovery Key.

The Recovery Key is generated locally. Its plain-text value is shown to the user when generated and is not persisted by GoldLock as plain text.

۴حساب کاربری و بازیابی آنلاین

قفل طلایی به حساب کاربری، نشانی ایمیل یا سرویس بازیابی آنلاین نیاز ندارد. بازیابی به‌گونه‌ای طراحی شده است که به‌صورت آفلاین و با کلید بازیابی کاربر انجام شود.

کلید بازیابی به‌صورت محلی ساخته می‌شود. هنگام ساخت، مقدار آن به‌شکل متن ساده به کاربر نمایش داده می‌شود، اما قفل طلایی آن را به‌صورت متن ساده ذخیره نمی‌کند.

5Third-Party Services

GoldLock does not use third-party analytics, advertising, tracking, or remote recovery services.

۵خدمات اشخاص ثالث

قفل طلایی از خدمات تحلیل‌گر، تبلیغات، ردیابی یا بازیابی از راه دورِ اشخاص ثالث استفاده نمی‌کند.

6Remote Code

GoldLock does not download or execute remote JavaScript or other remotely hosted executable code.

۶کد از راه دور

قفل طلایی جاوااسکریپت یا کد اجرایی دیگری را از راه دور دانلود یا اجرا نمی‌کند.

7Managed Protection

The optional Chrome Managed Protection feature relies on administrator policies configured outside the extension. GoldLock only reads the resulting managed state and does not modify Chrome policies from inside the extension.

۷محافظت مدیریت‌شده

قابلیت اختیاری محافظت مدیریت‌شدهٔ کروم به سیاست‌هایی متکی است که مدیر، خارج از افزونه پیکربندی می‌کند. قفل طلایی فقط وضعیت مدیریت‌شدهٔ حاصل را می‌خواند و از داخل افزونه سیاست‌های کروم را تغییر نمی‌دهد.

8Security

GoldLock uses cryptographic hashing with unique salts for local password and Recovery Key verification data. The extension is designed to keep the verification material inside the user's Chrome profile rather than transmitting it to a remote service.

۸امنیت

قفل طلایی برای داده‌های محلیِ تأیید گذرواژه و کلید بازیابی، از درهم‌سازی رمزنگاری‌شده همراه با نمک‌های یکتا استفاده می‌کند. افزونه طوری طراحی شده است که داده‌های تأیید را در نمایهٔ کروم کاربر نگه دارد و به سرویس راه دور منتقل نکند.

9Changes to This Policy

If GoldLock's data practices materially change, this Privacy Policy will be updated accordingly.

۹تغییرات این سیاست

اگر رویه‌های قفل طلایی در زمینهٔ داده‌ها به‌طور اساسی تغییر کنند، این سیاست حریم خصوصی نیز متناسب با آن به‌روزرسانی خواهد شد.
